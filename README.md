# GTA VI 30-Day Content Challenge

Interactive Vice City tracker for **VICEO** and **mr_clipco**.

Click a day to mark it done. The number next to the box is clips posted that day. Totals update live.

## Deploy on Vercel

1. Push this folder to a GitHub repo (or drag the folder onto [vercel.com/new](https://vercel.com/new)).
2. Import the project.
3. Framework Preset: **Other**. Leave Root Directory, Build Command, Output Directory empty.
4. Deploy.

After deploy, open the site, press **SHARE LIVE LINK**, send that URL to the other person. Both can tick days on the same board.

Without the live link the tracker still works on this device (local save).

## Local preview

```bash
python -m http.server 4177
```

Open `http://127.0.0.1:4177`.
